# 스냅 만들기 모드 카드 — 예시 입력/결과 이미지

`/wedding-snap/create` 페이지의 **1. 사진 업로드** 단계에서 사용자가 두 모드
(`셀카로 만들기` / `커플 사진으로 만들기`) 중 하나를 처음 고를 때, 카드 하단
에 "이런 사진을 넣으면 이런 결과가 나와요" 를 직관적으로 보여주는 대표 예시
1세트 (입력 사진 + 결과 사진).

각 모드 카드당 **입력 1장 + 결과 1장**만 사용 — 모든 카탈로그 결과를 깔지
않고 가볍게 이해도만 높이는 게 목적.

## 파일 규약

| 경로 | 용도 |
| --- | --- |
| `selfies-input.jpg` | 셀카로 만들기 카드 — 신랑·신부 셀카 입력 예시 (한 명만, 또는 콜라주) |
| `selfies-result.jpg` | 셀카로 만들기 카드 — 셀카 → 카탈로그 합성 결과 예시 |
| `couple-input.jpg` | 커플 사진으로 만들기 카드 — 커플 사진 1장 입력 예시 |
| `couple-result.jpg` | 커플 사진으로 만들기 카드 — 커플 사진 → 의상/배경 교체 결과 예시 |

코드 (`SnapGenerator.tsx`) 에서 ModeCard 의 `example` prop 으로 직접 path 가
지정되어 있어 별도 등록 작업은 필요 없음. **jpg 파일만 같은 이름으로 올리면
즉시 노출.**

## 권장 규격

- **비율**: 세로 3:4 또는 4:3 (카드 안 56×72px 정도로 작게 렌더 → 해상도는 자유)
- **해상도**: 가로 360px 이상 권장 (retina 대응)
- **용량**: 200KB 이하
- **내용**:
  - `selfies-input` — 정면 클로즈업 셀카 한 장. 안경/마스크 없는 자연 표정 권장.
  - `selfies-result` — 그 셀카로 만든 카탈로그 1컷의 베스트샷 (스튜디오 풀신
    추천 — 인풋과 시각적 대비가 커서 "와 이렇게 바뀌네!" 감이 강함).
  - `couple-input` — 두 사람이 함께 찍힌 정면 반신 컷.
  - `couple-result` — 그 사진을 베이스로 의상/배경만 바꾼 합성 결과.
- **컬러**: 두 사진의 톤이 너무 달라 보이지 않게. 자연광 daylight 추천.

## 파일이 없을 때

ModeCard 의 `ModeExampleThumb` 가 `onError` 로 자동 fallback — "준비 중"
placeholder 텍스트 박스 표시. 카드 자체는 정상 동작, 모드 선택 가능.
