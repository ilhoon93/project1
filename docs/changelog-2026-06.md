# Changelog — 2026-06 (알림장 / AI 웨딩스냅 개선 묶음)

이 문서는 2026년 6월 작업 묶음(PR #211~#223)에서 적용된 변경을 영역별로 정리한다.
세부 구현은 각 PR 설명을 참고.

## 알림장 — 배경음악(BGM)
- **공용 BGM 프리셋**: `/public/bgm/` 의 내장 곡을 에디터(테마 → 배경 음악)에서 선택. 파일명에
  `-` 가 있으면 "제목-아티스트"로 보고 **가사 있는 곡(가사 O)**, 없으면 연주곡(가사 X)으로 분류.
  (`src/lib/bgm-presets.ts`)
- **버그 수정**: `BgmSchema.url` 이 `z.string().url()` 이라 프리셋의 루트 상대경로(`/bgm/…`)를
  거부 → content 파싱이 통째로 실패해 **디자인이 초기화**되던 문제. http(s) URL 또는 `/` 경로를
  허용하도록 수정.
- **에디터에서 직접 URL 입력 필드 제거**(저작권 리스크). 프리셋 태그는 `가사 O`(초록)/`가사 X`(회색).
- **하객/소장용 화면 음악 ON/OFF 버튼**: 데스크톱 폰 프레임에서 `position:fixed` 라 프레임 밖으로
  떨어져 안 보이던 것을 `absolute` 로. 이후 **배경색·라벨 제거 → 아이콘만 + drop-shadow**(좌하단,
  콘텐츠 비가림). (`BgmPlayer`)

## 알림장 — 메인/뷰
- **메인 슬라이드 켄번스 효과**(풀배경 사진 18s 줌·팬, `prefers-reduced-motion` 비활성).
- **하객용 URL 데스크톱 폰 프레임**: 소장용(`/[slug]/o/[token]`)과 동일하게 가운데 폰 박스로.
- **제목 한글 폰트 4종 추가**(김정철명조·가비아 마음결·봄바람·흘림체). 애니메이션 선택 시 한글
  폰트가 폴백(noto-serif-kr)으로 그려지던 버그 수정 → `HandwritingStroke` 가 폰트 패밀리
  우선순위 순으로 서브셋을 고르도록.

## 알림장 — 방명록 / 투표 / 혼인서약서
- **소장용 방명록**: 같은 사람의 메시지+서명을 한 페이지에 통합, 넘기면 다음 사람. 책 높이를
  고정비율 → `min-height + 내용 높이`(짧은 글은 스크롤 없음, 긴 글만 확장). 서명 높이 축소.
- **방명록 서명 선택화**: 미서명 시 `null` 을 거부하던 서명 API 를 `nullable` 로 수정.
- **소장용 투표 결과 진행바**: 비율(%)만큼 칠해지도록. `bg-[var(--mw-accent)]/45`(hex 변수 +
  opacity modifier = 무효 CSS)였던 것을 `backgroundColor + opacity` 인라인으로 수정.
- **혼인서약서**: 금테 → 브랜드 코랄/크림 팔레트 리스킨. 다운로드(html2canvas) 시 청연체 이름과
  서명 밑줄이 겹치던 문제 수정(lineHeight/padding). (워터마크는 추가했다가 요청에 따라 제거)

## AI 웨딩스냅
- **예시보기 팝업(ExampleFlowModal) admin 설정화**: 흐름 구조(셀카 3행/커플 2행)는 고정, 이미지·
  카탈로그·텍스트를 `/admin/snap-samples` 에서 편집. `marketing_home_samples.example_flow`(jsonb,
  **migration 037**) 에 저장, null 이면 코드 기본값 폴백. 만들기 페이지 + 카탈로그 페이지(`/wedding-snap`)
  양쪽이 동일하게 admin 설정을 반영.
- **앵커 버튼**: 인물별 앵커 존재 여부로 "생성/재생성" 문구 분기.
- **커플 사진 업로드 UI**: 하단 "변경" 을 링크/버튼형 pill 로, "등록완료" 표기, **얼굴 감지 배지 제거**
  (측정값은 카탈로그 호환성 판정에 내부적으로만 사용).
- **마이페이지 결과 카드**: 이미지별 다운로드 버튼 + **합성 모드(기본 / 얼굴 강화) 칩** 표시
  (`snap_jobs.image_reference`).
- **카탈로그 '함께' 태그** 색을 검은색으로(신랑 파랑·신부 분홍과 구분).
- **알림장 디자인 샘플에 배경음악** 추가 가능(admin). 디자인 전체보기 모달에서 재생(`forceBgm`,
  표지/히어로는 무음).

## ⚠️ 배포/운영 주의
- **migration 037 (`example_flow` 컬럼) 적용 필수.** 미적용 시 `/admin` 의 홈샘플 저장
  (`saveHomeSamples` upsert)이 컬럼 없음 에러로 **전체 실패**한다(예시 흐름뿐 아니라 알림장/스냅 샘플
  저장 모두). 읽기는 폴백 처리되어 공개 페이지는 안전.
- **BGM 저작권**: 에디터의 직접 URL 입력은 제거했지만 **admin 샘플 BGM** 에는 직접 URL 입력이 남아
  있고, 샘플 음악은 디자인 전체보기 모달에서 공개 재생된다. 상업 서비스에서 무단 음원 사용은 위험 —
  로열티프리/CC0 또는 라이선스 보유 음원만 사용할 것.
- **예시 흐름 기본 이미지**: admin 미설정 시 `/public/wedding-snap/mode-examples/*.jpg` 정적 파일로
  폴백. 파일이 없으면 "준비 중" placeholder 로 표시된다.
